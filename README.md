# Tour Booking Site

A React app for browsing and booking tours: a searchable tour list, a detail page for each tour, and a booking flow with date selection.

## Features

- Tour list with search and filtering
- Tour detail pages
- Booking with date selection, including a Jalali (Persian) calendar
- Image carousel for tours
- Toast notifications for user feedback

## Built with

- React 18
- Vite 6
- Tailwind CSS 4
- React Router 7
- TanStack Query 5 and Axios for data fetching
- Swiper for carousels
- date-fns-jalali and react-multi-date-picker for Jalali dates
- react-hot-toast and react-icons

## Running locally

This app expects a backend API. Create a .env file and set VITE_BASE_URL to point at it.

```bash
npm install
npm run dev
```
